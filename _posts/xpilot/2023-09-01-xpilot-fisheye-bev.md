## 鱼眼镜头简介

### 从标准镜头到鱼眼镜头

普通镜头下的光线依据针孔相机模型进行成像, 但模型存在一个缺陷: 相机 FOV 越大, 所需要的成像平面就越大, 当相机视野范围为 180° 时, 所需要的成像平面为无穷大
在一些需要大角度视野的场景下, 为解决相机视野需求和成像平面之间的矛盾, 研究人员通过将一系列透镜进行组合, 使得光线出射角小于入射角度, 将大角度视野中的空间投影到有限尺寸的成像平面上
鱼类的眼睛在水下有 97° 视角, 但是由于光的折射作用, 鱼的视觉在水面上方会有160度的视角. 借鉴仿生学原理, 鱼眼镜头可以将相机的视场角扩大至 180° 以上

鱼眼镜头是一种焦距更短的并且视角(FOV)大于 160° 的广角镜头, 典型 FOV 是 180°~220°
它是一种极端的广角镜头, 外观与鱼的眼睛颇为相似

鱼眼镜头力求达到或超出人眼所能看到的范围. 因此, 鱼眼镜头与人们眼中的真实世界的景象存在很大的差别. 在相同画幅和像素尺寸下, 鱼眼镜头能容纳更多景物信息

鱼眼镜头和标准镜头的区别
FOV
标准镜头, 视场角在 45°-50° 左右, 和人眼的自然视场角相近
鱼眼镜头, 一般把视场角大于 160° 的广角镜头称为 鱼眼镜头, 典型 FOV 是 180°~220°

成像准则
一般光学系统遵循相似成像准则, 如标准相机采用的小孔成像模型
而鱼眼镜头为了将尽可能的将大的场景投影到有限的图像平面内采用了非相似成像的准则
投影模式
在标准相机中, 现实世界中的直线在图像平面上投影为直线, 平行的直线组被投影为一组直线, 这些直线在图像平面上的一个消失点上汇聚
鱼眼透视图与直线透视图有很大区别, 标准相机场景中的一条直线被投影为鱼眼图像面上的一条曲线, 平行线集被投影为一组在两个消失点上汇聚的曲线

Kannala-Brandt 模型

鱼眼镜头生产过程中不可能精确地按照投影模型来设计, 所以方便鱼眼相机的标定, Kannala-Brandt 在文[1]中提出了一种鱼眼相机的一般多项式近似模型. 作者将上述四个投影模型按入射角  进行泰勒级数展开, 形式如下:

2tan(\frac{\theta}{2}) = k_0\theta +  k_1{\theta}^3 + k_2{\theta}^5 + k_3{\theta}^7 + k_4{\theta}^9 + ... \\\\
2sin(\frac{\theta}{2}) = k_0\theta +  k_1{\theta}^3 + k_2{\theta}^5 + k_3{\theta}^7 + k_4{\theta}^9 + ... \\\\
sin(\theta) = k_0\theta +  k_1{\theta}^3 + k_2{\theta}^5 + k_3{\theta}^7 + k_4{\theta}^9 + ... \\\\
{\theta}_{d} = k_0\theta +  k_1{\theta}^3 + k_2{\theta}^5 + k_3{\theta}^7 + k_4{\theta}^9 + ...
记 为下式所示:

\theta_{d} = k_0\theta +  k_1{\theta}^3 + k_2{\theta}^5 + k_3{\theta}^7 + k_4{\theta}^9 + ...
则上述的投影模型均可以统一表述为: 

r(\theta) = f\theta_{d}
实验证明, 只需要取前 5 项, 便具有足够的自由度来很好的近似各种投影模型. 其中  取 1, 标定时即标定  参数. 令  ,  即为相机的畸变系数.
这种模型可以通过入射角  得到 ，通过无畸变图像中的点能够计算出鱼眼图像中的畸变点. OpenCV中鱼眼相机标定方法就是用的这种 KB 模型.

鱼眼镜头畸变分类
鱼眼镜头的畸变分为径向畸变和切向畸变, 一般是径向畸变会非常严重, 所以畸变模型主要考虑的是径向畸变.

 径向畸变
枕形畸变和桶形畸变
产生的原因在于: 透镜自身形状(如厚、薄)对光线传播产生影响, 距离镜头越远的场景的光线就越弯曲从而产生径向畸变
切向畸变
薄透镜畸变和离心畸变
产生的原因在于: 相机在组装过程中难以使得透镜和成像平面严格平行而引起切向畸变





切向畸变可以看作坐标点的水平角发生改变, 用多项式进行径向和切向畸变拟合:

归一化平面上的点 , 用极坐标  表示,  为  与归一化平面原点之间的距离.

x_{distort} = x(1 + k_1r^2 + k_2r^4 + k_3r^6 + 2p_1xy + p_2(r^2 + 2x^2))  \\\\
y_{distort} = y(1 + k_1r^2 + k_2r^4 + k_3r^6 + 2p_2xy + p_1(r^2 + 2y^2)) 
 为径向畸变系数;



切向畸变由镜头制造工艺和安装的精细程度, 是的透镜本身和图像平面不平行而产生切向畸变. 假设畸变位置坐标 , 畸变校正后的坐标与畸变点的坐标关系表示如下:

x_{corrected} = x + [2p_1y + p_2(r^2 + 2x^2)] \\\\
y_{corrected} = y + [2p_2x + p_1(r^2 + 2y^2)]

Kannala-Brandt 模型

鱼眼镜头生产过程中不可能精确地按照投影模型来设计, 所以方便鱼眼相机的标定, Kannala-Brandt 在文[1]中提出了一种鱼眼相机的一般多项式近似模型. 作者将上述四个投影模型按入射角  进行泰勒级数展开, 形式如下:

2tan(\frac{\theta}{2}) = k_0\theta +  k_1{\theta}^3 + k_2{\theta}^5 + k_3{\theta}^7 + k_4{\theta}^9 + ... \\\\
2sin(\frac{\theta}{2}) = k_0\theta +  k_1{\theta}^3 + k_2{\theta}^5 + k_3{\theta}^7 + k_4{\theta}^9 + ... \\\\
sin(\theta) = k_0\theta +  k_1{\theta}^3 + k_2{\theta}^5 + k_3{\theta}^7 + k_4{\theta}^9 + ... \\\\
{\theta}_{d} = k_0\theta +  k_1{\theta}^3 + k_2{\theta}^5 + k_3{\theta}^7 + k_4{\theta}^9 + ...
记 为下式所示:

\theta_{d} = k_0\theta +  k_1{\theta}^3 + k_2{\theta}^5 + k_3{\theta}^7 + k_4{\theta}^9 + ...
则上述的投影模型均可以统一表述为: 

r(\theta) = f\theta_{d}
实验证明, 只需要取前 5 项, 便具有足够的自由度来很好的近似各种投影模型. 其中  取 1, 标定时即标定  参数. 令  ,  即为相机的畸变系数.
这种模型可以通过入射角  得到 ，通过无畸变图像中的点能够计算出鱼眼图像中的畸变点. OpenCV中鱼眼相机标定方法就是用的这种 KB 模型.

鱼眼镜头畸变分类
鱼眼镜头的畸变分为径向畸变和切向畸变, 一般是径向畸变会非常严重, 所以畸变模型主要考虑的是径向畸变.

 径向畸变
枕形畸变和桶形畸变
产生的原因在于: 透镜自身形状(如厚、薄)对光线传播产生影响, 距离镜头越远的场景的光线就越弯曲从而产生径向畸变
切向畸变
薄透镜畸变和离心畸变
产生的原因在于: 相机在组装过程中难以使得透镜和成像平面严格平行而引起切向畸变





切向畸变可以看作坐标点的水平角发生改变, 用多项式进行径向和切向畸变拟合:

归一化平面上的点 , 用极坐标  表示,  为  与归一化平面原点之间的距离.

x_{distort} = x(1 + k_1r^2 + k_2r^4 + k_3r^6 + 2p_1xy + p_2(r^2 + 2x^2))  \\\\
y_{distort} = y(1 + k_1r^2 + k_2r^4 + k_3r^6 + 2p_2xy + p_1(r^2 + 2y^2)) 
 为径向畸变系数;



切向畸变由镜头制造工艺和安装的精细程度, 是的透镜本身和图像平面不平行而产生切向畸变. 假设畸变位置坐标 , 畸变校正后的坐标与畸变点的坐标关系表示如下:

x_{corrected} = x + [2p_1y + p_2(r^2 + 2x^2)] \\\\
y_{corrected} = y + [2p_2x + p_1(r^2 + 2y^2)]

鱼眼透视图和直线透视图有很大区别, 在鱼眼场景中, 一条直线会被投影为图像平面上的一条曲线, 两条平行线被投影为一组在两个消失点汇聚的曲线, 这种失真并不是唯一的影响.鱼眼图像对目标检测卷积方法中假设的平移不变性有影响, 在标准相机中, 这种假设是可以接受的, 但是在鱼眼相机中, 需要仔细考虑如何处理这一点, 具体参考论文[4]
